# QuickClass 使用文档

**QuickClass（觉课智能体）** 是一个 AI 驱动的课堂教学辅助平台，帮助教师创建互动式学习活动、管理课堂作业、分析学情数据，让学生在与 AI 的对话与探究中深度学习。

> 面向对象：一线教师、教研人员、平台部署者。

## 核心能力

| 能力 | 说明 |
|---|---|
| 💬 **对话活动** | 学生与 AI 进行主题对话，围绕知识点深入探究 |
| 🧩 **互动探究** | HTML 交互式学习活动，支持成果提交与 AI 学伴 |
| 📦 **项目提交** | 学生提交作品，全班互看互评，支持置顶、下架与点赞 |
| 📝 **课堂作业** | 在线答题，AI 自动批改，即时反馈 |
| 📊 **学情分析** | AI 自动生成个人与全班分析报告，附可视化大屏 |
| 🔬 **教学研究** | 基于课堂数据一键生成研究论文（数据快照机制） |
| 📚 **知识库** | 上传教学资料，AI 对话与学情分析自动引用 |
| 🗂️ **优秀课例库** | 一线教师共享的完整课堂设计，一键导入到自己的课堂 |
| 📄 **手册导出** | 一键导出教学手册（教案）与学习手册（学案）Word |

---

## 适用场景

- 课堂教学中的个性化辅导
- 课后作业布置与批改
- 学情数据采集与分析
- 探究式、项目式学习活动设计

## 配套工具：WorkBuddy 技能
