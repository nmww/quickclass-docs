# WorkBuddy 技能支持

WorkBuddy 是 AI 助手平台，其技能市场提供 QuickClass 专用技能，能把现成的教案、试卷直接转成 QuickClass 可导入的 JSON，省去逐条录入的功夫。

---

## 一、可用技能

| 技能 | 输入 | 输出 |
|---|---|---|
| QuickClass 课堂转换器 | 教案 / 学习材料（Word、PDF、图片） | 完整课堂 JSON（对话活动 + 课堂作业 + 互动探究 + 项目提交 + 知识库） |
| QuickClass 作业转换器 | 试卷（Word、PDF、图片） | 课堂作业 JSON（题目） |

---

## 二、安装与启用

1. 打开 WorkBuddy 左侧「专家 · 技能 · 连接器」
2. 在技能市场搜索 `QuickClass`
3. 点开技能卡片按提示安装
4. 在「我安装的」里确认技能在列，卡片右上角开关变绿即为启用

---

## 三、调用方式

在 WorkBuddy 对话中直接 @ 技能并附上文件：

```
@skill:"QuickClass课堂转换器" @"D:/work/Quickclass/北京的春节教案.docx"
```

也可在新建任务时，从「技能」列表中直接选中。

---

## 四、课堂转换器会做什么

| 步骤 | 技能做的事 | 教案变成什么 |
|---|---|---|
| ① | 读取教案，提取课题、年级、学科、目标 | 课堂顶层信息 |
| ② | 把教学环节拆成「导入 / 新授 / 练习总结」 | 2–3 个对话活动 |
| ③ | 提取练习题并识别题型 | 课堂作业（单选 / 多选 / 判断） |
| ④ | 识别探究任务或 HTML 资源 | 互动探究活动 |
| ⑤ | 识别作品提交要求 | 项目提交配置 |
| ⑥ | 封装知识库 + 学情分析提示词 | 完整课堂 JSON |

生成的 JSON 按规范命名，导入时能自动识别：

```
{教师}_{年级}_{学科}_{课堂标题}_{日期}_课堂.json
```

---

## 五、导入 QuickClass

教师端 → **课堂管理** → 页面上方「**导入课堂**」→ 选择 JSON 文件。

!!! tip "别点错"
    「导入作业」在课堂作业区域，「导入课堂」在课堂列表区域，两者不是一回事。

导入后检查无误、确认活动状态后即可启用（详见[导入导出与知识库](guide/import-export.md)）。

---

## 六、三种使用姿势

- **教案进课堂**：已有现成教案，直接交给技能，几分钟得到完整课堂 JSON
- **从零搭一节课**：没有教案时，告诉技能「X 年级 X 学科《课题》」，它会通过对话收集教材版本、核心知识点、能力侧重、学生水平等再生成。**务必说明教材版本**，不同版本知识点顺序与术语差异很大
- **改造旧课**：只有旧作业 JSON 时，把原教案交给技能，可补齐对话、探究、项目提交

---

## 七、配套：导出教学手册与学习手册

课堂导入并调整好后，可在课堂管理页一键导出 Word 手册（见[系统配置与手册导出](guide/settings.md)）：

- **教学手册**：自己备课、教研存档、公开课教案
- **学习手册**：直接打印发给学生当学案

---

## 八、注意事项

!!! warning "教师必须把关"
    - AI 负责把教案「翻译」成结构，但**学科正确性、题目质量、探究难度必须教师亲自把关**
    - 导入后先自己走一遍：对话活动开场白是否场景化、作业题目数量与正确答案、探究 HTML 是否正常显示
    - 课堂作业仅支持单选、多选、判断三种题型
