## 🔬 抢先体验版（dev 最新 · 魔搭空间实时运行） {#dev-latest}

!!! warning "这是 dev 分支抢先体验内容"
    以下内容已在魔搭体验环境 [modeai-quickclass.ms.show](https://modeai-quickclass.ms.show) 上线，属于 **dev 分支抢先体验**，**尚未并入正式发布版本（main / release）**，版本号仍记为 v2026.10.22。正式发布后会并入下方「更新记录」对应版本。

### 🎉 新增功能

- **课堂分析页层级切换**：课堂分析页新增「课堂 / 对话活动」层级切换入口，先看课堂整体、再下钻到具体对话活动
- **对话记录标签筛选**：对话记录列表的姓名 / 班级 / 课堂 / 活动标签均可点击，一键筛选对应数据

### 🛠️ 修复问题

- **邀请码登录不再建幽灵账号**：邀请码登录不再凭学号创建幽灵账号（issue IKPPYQ）
- **作业报告统计口径修正**：修正作业报告参与率与正确率统计口径；统计标签改称「已完成作答」，与 AI 报告参与人数区分（issue IKPO3W）
- **姓名筛选精确匹配**：姓名筛选改用 userId 精确匹配 + 话筒提示 4 秒节流（IKPPFV / IKP4FC）
- **麦克风与语音提示更友好**：麦克风失败按原因给出可操作提示；语音输入未配置语音模型时给出引导而非英文报错
- **学生对话布局修复**：修复学生对话流式闪动与长内容撑破布局的问题
- **课堂管理聚焦修复**：切 tab 返回课堂管理时恢复独占聚焦，修掉「展开的课堂与其余课堂同时可见」
- **学生端加载卡死修复**：部署后旧页面自动重载，修掉学生端卡在「加载中」
- **AI 朗读音色恢复**：msedge-tts 升级 2.1.1，恢复微软神经音色朗读
- **移动端视口适配**：移动端视口高度改用 dvh，输入框不再被浏览器地址栏遮挡

### 🧹 内部优化

- 清理 84 处调试 `console.log`；新增 `no-console` / `no-empty` lint 规则，给调试输出与空代码块止血

## v2026.10.22

### 🎉 新增功能

- **对话活动「查看对话」**：教师端对话活动分析窗口的学生卡片新增「查看对话」按钮，弹窗浏览该学生在当前对话活动的全部对话（只读），支持语音播放与 Markdown 正文渲染，按班级 + 活动精确筛选

### 🛠️ 修复问题

- **学生对话超限提示人话**：max tokens 超限报错改为清晰提示，引导学生联系老师更换 64K+ 大模型
- **作业题目换行丢失**：Markdown 渲染启用 breaks，题目换行在报告中完整保真

## v2026.10.21

### 🎉 新增功能

- **语音对话**：学生端对话可录音提问，语音自动转成文字存入对话记录——既能看文字又能听原声，AI 分析不受影响（需在系统设置配置全媒体模型）
- **拍照 / 传图 / 添加文件**：对话输入栏支持页内拍照、上传图片与文件，AI 可结合图片内容作答
- **教师端「AI 帮我写」**：活动目标、分析模板一键 AI 起草，配套模板写作指南与图表协议，生成后可继续修改
- **交互探究数据采集**：闯关、得分、行为流自动采集落库，教师端可查提交详情；采集数据接入课堂学情分析与教研科研
- **探究数据大屏 DIY**：支持手动编辑、AI 重排、恢复默认三种方式调整大屏布局
- **教师端主题换肤**：多套配色主题一键切换
- **报告导出**：文本型分析报告底部新增导出 PDF 按钮，docx 导出体验优化
- **预设对话教师开场白**：学生进入对话即收到老师预设的开场引导

### ✨ 功能增强

- **AI 模型双线路主备**：主模型故障自动切换备用；新增「全媒体线路（语音 / 图片 / 视频分析）」独立配置主备模型
- **长任务不再被掐断**：伴学、交互探究、教研科研等长思考任务只防「连接不成功」，不再误报超时
- **分析模板预览升级**：作业设计类 JSON 模板预览自动格式化，不再显示裸源码
- **外部内容嵌入**：对话与探究支持嵌入飞象老师生成的动画等外部链接
- **一键在线更新**：系统设置新增「一键在线更新」入口，平台可自检新版本
- **课堂管理细节**：班级支持改名；课堂活动统一跨类型排序；列表分页优化

### 🛠️ 修复问题

- **报告页全屏显示**：课堂 / 对话分析等报告的全屏展示统一修复
- **编辑弹窗误关闭**：编辑课堂、对话、项目、互动探究等弹窗，点击窗外或按 ESC 不再误关闭，防止未保存内容丢失
- **AI 朗读拼音**：朗读文本中的拼音注音自动转汉字，不再逐字母念拼音
- **流程图渲染**：AI 流程图渲染失败不再残留错误图；对话刷新后流程图正常显示
- **教师端样式**：修复多个页面失效样式导致的透明底白字问题
- **语音未配置提示**：未配置语音模型时，学生发语音会看到清晰的开启指引，不再报代码错误

## v2026.09.23

### 🎉 新增功能

- **图片仓库**：教师端新增「图片仓库」，课堂用图可统一上传、分组管理；出题与对话时选中相应的图片组，AI 会自动结合图片内容作答
- **分析模板效果预览**：在模板管理里可直接预览「这份模板会产出什么样的报告」，不用先跑一遍真实课堂数据

### ✨ 功能增强

- **学生端适配平板与手机**：对话、答题、互动探究、项目提交等页面在窄屏自动切换紧凑布局 —— 朗读控件收敛为小图标、输入框与底部按钮同高、页头标题不再被挤成竖排；平板横屏与桌面布局保持不变
- **分析模板升级（可选模板 14 → 20 个）**：模板中的图表改由系统按数据确定性渲染，图形更规范、不会画错；同时保留「手绘图表版」风格供选择，老师可在模板管理中按需挑选
- **作业解题思路**：学生查看作业结果时，每道题都能看到解题思路（错题默认展开，答对的题可点开）
- **教师端课堂管理记住浏览位置**：翻页、切换筛选后返回列表，不再跳回顶部
- **对话记录分页浏览**：师生对话记录支持分页，每页条数可自行选择
- **AI 回复支持流程图**：回复中若包含流程图，会自动渲染成图形便于讲解

### 🛠️ 修复问题

- **首页「更新记录」显示旧内容**：远程版本信息比平台内置的旧时会覆盖掉最新文案，现改为多源比对版本号后取最新
- **学生端对话滚动异常**：收到新消息时只滚动消息区，不再把整个页面顶走
- **AI 朗读没有反应**：浏览器没有可用语音时现在会给出明确提示，不再静默失败
- **AI 偶发空回复**：遇到空回复会自动重试一次，并如实说明原因

## v2026.09.08

### 🛠️ 修复问题

- **课堂作业「全做对却得分不满」**：AI 出题返回的非规范题型会原样入库，批改时被跳过并按答错记 0 分；现已从源头归一化题型
- **主观题（填空 / 简答）AI 批阅结果被丢弃**：批阅结果现可正确对号入座
- **批改结果与「答错」无法区分**：未批改的题现标记为「未批改」并写入原因

### ✨ 功能增强

- 新增统一的题型归一化逻辑，出题解析与入库两处二次归一化，从源头杜绝脏题型
- 学生端作业结果一律以后端判定为准，新增每题得分展示与「未批改」标记
- 教师端加载题目时自动修正非法题型并提示，保存前校验题型合法性
