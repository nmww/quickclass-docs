# 学生端

学生端无需复杂注册，凭**班级邀请码**即可进入课堂。

---

## 一、加入班级与登录

### 加入班级

1. 浏览器访问 `http://<教师电脑IP>:3000/student`
2. 输入教师提供的**邀请码**
3. 输入姓名
4. 点击「加入」——系统自动创建账号并加入对应班级

### 登录

- 已有账号的学生：输入姓名和密码登录
- 无密码的学生：输入姓名和邀请码登录

---

## 二、对话活动学习

1. 登录后进入对话页面
2. 左侧显示当前课堂和对话活动列表
3. 点击对话活动名称，开始与 AI 对话
4. 对话内容会被记录，教师可查看和分析

---

## 三、互动探究

1. 在对话页面右侧，点击「互动探究」标签
2. 选择探究活动
3. 在 HTML 交互界面中完成学习任务
4. 点击「提交」提交探究结果

---

## 四、项目提交

「项目提交」与对话、互动探究、作业并列，位于课堂内。学生进入课堂后点「项目提交」查看教师布置的任务。

### 提交与编辑自己的项目

1. 进入课堂，点击「项目提交」标签
2. 选择某一项任务，查看教师要求（类别、大小限制）
3. 点击「提交」，填写标题与说明，按类别上传**一个文件**（文本类 doc/pdf，图片类 jpg/png，音视频类 mp4 等）
4. 已提交后可编辑、删除、重新提交自己的项目
5. 附件：图片 / 视频直接预览，文本类下载
6. 可看到自己提交被「置顶」或「下架」的状态提示

### 互看与点赞

- 若任务全班可见：可看到本班其他同学的项目，并看到各项目点赞数
- 若任务允许点赞：可给他人项目点赞 / 取消（**不可给自己点**）
- 被下架的项目不显示在他人列表中（仅自己和教师可见）
- 范围仅限本课堂本班，不跨班

---

## 五、课堂作业答题

1. 在对话页面右侧，点击「课堂作业」标签
2. 选择要完成的作业
3. 逐题作答，提交后自动批改
4. 可查看得分和正确答案

---

## 六、我的学情分析

1. 登录后，点击顶部的「学情分析」
2. 查看教师在课堂层级为该学生生成的个人学情分析报告

!!! note "学生看到的是课堂级分析"
    学生端展示的学情分析是**课堂层级**的个人综合分析，涵盖该课堂下所有对话活动、作业和探究的数据，而非单个对话活动的分析。对话活动层级的分析仅供教师在管理端查看。
