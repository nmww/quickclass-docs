# 导入导出与知识库

---

## 一、课堂导出

QuickClass 支持将整个课堂结构导出为 JSON 文件，分享给其他教师后由对方「导入课堂」一键重建。导出内容包含四类学生活动：**对话活动、课堂作业（含全部题目）、互动探究、项目提交**，以及被引用的知识库。

### 导出步骤

1. 进入「课堂管理」页面
2. 在目标课堂卡片右上角点击「导出课堂」图标
3. 浏览器自动下载一个 JSON 文件

!!! info "出处标记"
    导出的课堂标题会自动追加 `_来源于_原教师姓名` 后缀（如 `一元一次方程_来源于_张老师`）。对方导入后课堂名称保留该出处，便于追溯来源。

---

## 二、课堂导入

1. 在「课堂管理」页面顶部，点击「**导入课堂**」按钮
2. 选择本机上的课堂 JSON 文件（即他人导出的文件）
3. 系统自动重建课堂，并带出：

    - 所有对话活动及提示词
    - 所有课堂作业及其题目（单选 / 多选 / 判断）
    - 所有互动探究活动
    - 所有项目提交任务

4. 若原课堂引用了知识库，导入时会在你账号下**自动创建或复用同名知识库**并关联

### 导入后的注意事项

| 项目 | 导入后状态 | 你需要做的 |
|---|---|---|
| 课堂 | 默认启用（可在课堂管理看到） | 检查内容后再布置给学生 |
| 课堂作业 | 未生效 | 检查题目后重新发布 |
| 知识库 | 已创建并关联 | 可在知识库管理查看，名称含导入者 + 出处 |

!!! note "只重建教学结构"
    导入的课堂**不会**带入原教师、学生、班级及任何对话 / 答题记录，仅恢复教学结构本身。

!!! tip "别点错"
    「导入作业」在课堂作业区域，「导入课堂」在课堂列表区域，两者不是一回事。

---

## 三、优秀课例库

「优秀课例库」收录一线教师共享的完整课堂设计，可直接参考，也可**一键导入到自己的课堂**再修改。

- 进入「优秀课例库」页面，可按年级筛选、按课题 / 单元 / 提供者搜索
- 点击「查看详情」预览课例的作业、探究、预设对话、项目提交与配套知识库
- 点击「导入到我的课堂」即在你的账号下生成一份可编辑的课堂
- 已导入的课例会显示「**已导入**」标记，**刷新后依然保留**，重复导入会自动去重

---

## 四、知识库

知识库是上传的 `.md` 或 `.txt` 教学资料。被课堂引用后，学生在该课堂的 AI 对话、教师的学情分析中，AI 会基于知识库内容来回答和生成报告。

### 新建知识库

1. 进入「知识库管理」页面
2. 点击「新建知识库」
3. 输入名称，拖拽或选择上传 `.md` / `.txt` 文件（上限 50,000 字符）
4. 保存后自动启用

### 编辑与预览

- 可修改名称，重新上传文件替换内容；修改后**立即生效**，不影响已引用的课堂
- 点击知识库旁的「预览」查看全文内容

### 启用 / 禁用 / 删除

- 禁用的知识库不会出现在课堂引用列表中，已引用的课堂不受影响
- 删除前弹出确认对话框，显示被哪些课堂引用；确认后级联删除，相关课堂的引用关联自动移除

### 在课堂中引用

1. 创建或编辑课堂时，在「引用知识库」区域勾选目标知识库
2. 可同时引用多个，总计不超过 50,000 字符
3. 保存后，学生在该课堂的 AI 对话会基于知识库内容回答
4. 展开课堂卡片可看到已引用的知识库名称和字符数

### 导入课堂时的知识库处理

- 若导入的课堂引用了知识库，会在你账号下自动创建或复用同名知识库
- 自动创建的知识库命名格式：`导入者姓名_课堂标题_知识库名_导入日期`
