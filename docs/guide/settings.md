# 系统配置与手册导出

---

## 一、系统配置

进入「系统设置」页面，包含以下配置。

### AI 服务配置

| 配置项 | 说明 |
|---|---|
| API Base URL | AI 服务地址，支持 OpenAI 兼容接口（通义千问、DeepSeek、智谱等） |
| API Key | API 密钥（不对外泄露） |
| AI 模型 | 模型名称，如 `qwen-turbo`、`deepseek-chat` |
| 推理思考模式 | 仅 DeepSeek V4 系列支持，返回推理过程 |
| AI 并发限制 | 同时处理的 AI 请求数：小班 10–20、中班 20–40、大班 40–100 |
| 测试连接 | 验证 AI 服务是否可用 |

!!! tip "常见 Base URL 示例"
    通义千问（百炼）：`https://dashscope.aliyuncs.com/compatible-mode/v1`

### 用户信息设置

- 修改单位（学校）
- 设置老师座右铭（显示在工作台）
- 设置学生座右铭（统一显示在所有学生端）
- 修改密码

### 学情洞察配置

| 配置项 | 说明 |
|---|---|
| 启动指数评价 | 开启后学生分析只输出星级评分（6–10 星），不显示文字 |
| 个人分析字数上限 | 建议 100–5000 字，留空不限 |
| 班级分析字数上限 | 建议 200–10000 字，留空不限 |

### 配置备份与导入

- 可导出当前配置为 JSON 文件
- 可导入 JSON 配置文件恢复设置

## 二、教学手册与学习手册导出

教师端可为每个课堂一键导出两份 Word 手册，面向对象和用途完全不同：

| 手册 | 按钮 | 文件名 | 面向对象 | 是否含答案 |
|---|---|---|---|---|
| 教学手册 | 导出手册 | `{课堂名}_教学手册.docx` | 教师（备课 / 教研 / 存档） | 含 |
| 学习手册 | 导出学习手册 | `{课堂名}_学习手册.docx` | 学生（学案，可直接打印） | 不含 |

**入口**：「课堂管理」页面 → 目标课堂卡片上的按钮（鼠标悬停显示「导出手册」「导出学习手册」）。

### 教学手册（教师教案）

按 30 分钟课时组织，结构如下：

- **封面**：教师姓名、单位、年级、学科、来源
- **一、教学目标**：按学科核心素养逐条列出具体目标
- **二、教学活动**：每个活动含活动目标、活动内容、教师指导、学生反馈应对、QuickClass 操作指导，并附活动之间的过渡语
- **三、课堂作业设计**：逐题列出题目内容、选项、答案与解析
- **四、教学反思**：课后自评记录框架
- **五、备用活动**：超出 30 分钟限时的活动自动移入此节

适用于公开课教案、教研存档、校内分享、代课交接。

### 学习手册（学生学案）

只收录**学生端可见且已启用**的活动，结构如下：

- **封面**：班级 / 姓名 / 日期填写栏
- **一、我的学习目标**：逐条列出，供学生自评
- **二、课堂任务单**：对话 / 探究 / 作业 / 项目，每项带勾选框、学生要做的事与提示
- **三、随堂练习**：课堂作业题目 + 作答区，**不含参考答案**
- **四、我的学习小结**：自评填空
- **附录：本课知识点**：课堂引用的知识库与教学内容合并整理

空章节会自动跳过（如本课无作业则不出现「随堂练习」），导出后可直接打印发给学生。

!!! warning "导出前先确认活动状态"
    学习手册只导出**已生效的作业**以及**已启用的对话、探究、项目**。某项活动未发布就不会出现在学案里，导出前请先确认活动状态。
