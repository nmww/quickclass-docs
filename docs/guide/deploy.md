# 部署指南

QuickClass 提供两种使用方式：**直接使用在线演示环境**，或**自建部署**以满足数据长期保存与正式教学的需求。

---

## 一、在线演示环境（零部署试跑）

官方演示环境已内置完整演示数据，**教师与学生全部功能可直接体验**，无需任何准备。

- 教师：手机号 `13800138000` / 密码 `123456`
- 学生：凭班级邀请码免密进入

!!! warning "演示环境数据不长期保存"
    容器重启或平台更新后会重建演示账号与演示班级，你创建的班级、课堂与对话记录也会被清空。**请勿录入重要或真实信息**，学生建议使用化名。正式教学请自建部署。

## 二、自建部署

### 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | macOS、Windows、Linux |
| Node.js | 18.17 或更高版本 |
| npm | 9.x 或更高版本 |

确认版本：

```bash
node --version   # 应显示 v18.17.0 或更高
npm --version    # 应显示 9.x 或更高
```

### 启动服务

=== "macOS / Linux"

    ```bash
    ./start.sh     # 启动，浏览器自动打开 http://localhost:3000
    ./stop.sh      # 停止
    ```

    若提示「权限被拒绝」，先执行 `chmod +x start.sh stop.sh`。

=== "Windows"

    双击项目目录下的 `start.bat` 启动（约 1–2 分钟），双击 `stop.bat` 停止。

### 常用命令

```bash
npm run dev        # 开发模式启动（不推荐生产使用）
npm run build      # 构建生产版本
npm start          # 生产模式启动
npm run db:push    # 同步数据库结构
npm run db:seed    # 填充示例数据
```

## 三、首次使用配置

### 1. 注册教师账号

访问 `http://localhost:3000` → 「教师注册」→ 填写手机号、密码、姓名 → 完成注册。

### 2. 配置 AI 服务

进入「系统设置」：

1. 填写 **AI Base URL**（如 `https://dashscope.aliyuncs.com/compatible-mode/v1`）
2. 填写 **API Key**
3. 选择 **AI 模型**（如 `qwen-turbo`）
4. 点击「测试连接」确认配置正确
5. 点击「保存配置」

### 3. 创建班级与课堂

- 「班级管理」→ 创建班级 → 记录**邀请码**
- 「课堂管理」→ 创建课堂 → 添加学习活动 → 分配班级 → 「启用」

### 4. 学生加入

学生访问 `http://<教师电脑IP>:3000/student`，输入姓名 + 邀请码即可开始学习。

## 四、生产环境建议

- **数据库**：默认使用单文件 SQLite（`prisma/dev.db`）。正式环境建议改用独立数据库，并定期备份 `prisma/dev.db`。
- **反向代理**：建议置于 Nginx / Caddy 之后并启用 HTTPS。
- **鉴权头**：若部署在会改写 `Authorization` 头的网关 / 代理后（如魔搭创空间），请确保前端使用 `x-auth-token` 传递令牌。
- **密钥安全**：AI API Key 仅保存在你自己的环境，请勿公开。

## 五、常见问题

**Q：启动脚本报错「权限被拒绝」？**
A：macOS / Linux 上执行 `chmod +x start.sh stop.sh`。

**Q：Windows 上启动后浏览器未自动打开？**
A：手动访问 `http://localhost:3000`。

**Q：学生无法访问教师电脑上的服务？**
A：确保教师电脑防火墙允许 3000 端口，学生使用局域网 IP 访问（如 `http://192.168.1.100:3000`）。

**Q：AI 无法回答问题？**
A：检查「系统设置」中 API Key 是否正确，点击「测试连接」验证。

**Q：如何备份数据？**
A：停止服务后，复制 `prisma/dev.db` 文件到安全位置。
