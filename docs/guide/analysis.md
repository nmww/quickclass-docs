# 学情分析与教学研究

---

## 一、对话记录查看与删除

1. 进入「对话记录」页面
2. 可按班级、课堂、对话活动筛选
3. 可按学生姓名搜索
4. 展开对话可查看完整聊天记录
5. 支持单个删除和批量删除
6. 支持清空某个班级的所有对话记录

---

## 二、学情分析

学情分析是 QuickClass 的核心功能，基于学生的对话记录、AI 伴学对话、作业答题数据，AI 自动生成分析报告。分析分为**个人分析**和**全班分析**两个维度。

### 进入学情分析

- 在课堂列表中，点击课堂旁的「分析」按钮
- 或进入「课堂管理」→ 展开课堂 → 点击对话活动旁的「分析」

### 分析层级

- **对话活动层级**：选择具体对话活动查看该活动下的分析（仅教师端可见）
- **课堂层级**：查看整个课堂的综合分析，其中**个人分析会同步展示给学生端**

### 课堂级分析数据来源

| 数据类型 | 说明 |
|---|---|
| 预设对话 | 学生在各对话活动中与 AI 的对话记录 |
| AI 伴学对话 | 学生在互动探究中与 AI 伴学的对话记录，自动纳入课堂级分析 |
| 课堂作业 | 答题得分、正确率及班级统计 |
| 子分析报告（聚合模式） | 各对话活动已生成的分析摘要 |

!!! note
    AI 伴学对话仅用于**课堂级分析**（班级 / 个人），对话活动级分析不含此类数据。

### 对话学情分析

**个人分析**

- 选择具体学生，点击「生成分析」
- AI 根据该学生的对话内容分析：知识理解程度与薄弱点、思维过程与表达特点、学习建议与改进方向
- 支持**批量一键分析**所有学生
- 分析结果按星级指数排序，快速定位需要关注的学生

**全班分析**

- 点击「生成班级分析」，AI 汇总全班对话数据生成整体报告
- 报告包含两种呈现形式：

    - **文本分析**：班级整体掌握情况、共性问题、教学建议
    - **HTML 大屏分析**（适合课堂投屏）：班级整体掌握度雷达图、各知识点理解程度柱状图、学生分布散点图、关键指标统计卡片

- 支持多版本管理，可对比不同时间点的分析结果

### 互动探究分析

- **个人分析**：查看学生探究提交详情（操作过程与交互记录、得分与完成情况、AI 学习建议），支持查看操作日志
- **全班分析**：完成率、平均得分、得分分布、共性问题、教学建议，附可视化大屏
- 支持多版本管理和版本对比

### 作业分析

- **个人分析**：各题答题情况与正误、总分与题型得分、AI 错题分析与学习建议，支持查看具体答案与批改结果
- **全班分析**：全班正确率、平均分、得分分布、典型错误、教学建议，附可视化大屏
- 支持多版本管理和版本对比

### 分析提示词模板

- 系统内置多种分析提示词模板
- 教师可自定义模板，控制分析报告的格式和侧重点
- 支持 AI 自动生成提示词
- 发送前可预览完整 Prompt，确认后执行

## 三、教学研究（AI 论文生成）

教学研究功能基于课堂数据（学生对话、课堂作业、学情分析报告）一键生成研究论文。其底层采用**数据快照**机制，理解以下两点有助于正确使用。

### 数据快照（冻结机制）

- 创建研究项目时，系统会**实时扫描数据库**，把所选的对话、作业、报告**一次性打包成一份 JSON 快照**，存入该项目记录中。
- 快照是原始教学数据的**独立副本**，而非实时引用。因此：

    - 你对数据库里学生对话、作业的**后续增删改，不会影响已创建的研究项目**
    - 即使你删除了全部对话记录，已生成或重新生成的论文**仍基于创建时冻结的那份快照**

- 重新生成论文读取的是创建时冻结的快照，**不会**回头重新扫描数据库——论文因此可复现。

### 删除即删除快照

- 删除研究项目时，整条项目记录（含快照、已生成论文、标题、数据范围等）**从数据库物理删除**，无残留、无回收站。
- 删除项目**只删这份副本，不会动数据库中学生真实的对话、作业、报告**等原始教学数据。

### 想用新数据生成论文怎么办

由于重新生成仍用旧快照，若希望论文反映**最新教学数据**，请**新建一个研究项目**（新建时会重新扫描数据库抓取最新数据），而不是在旧项目上重新生成。
