# 快速上手

本文带你从零跑通一节课：登录 → 配置 AI → 建班级 → 建课堂 → 学生加入。

---

## 一、进入平台

QuickClass 是一个 Web 应用，浏览器打开地址即可使用：

- **教师端**：访问站点根地址 → 教师登录 / 注册
- **学生端**：访问 `/student` → 输入邀请码 + 姓名进入

!!! info "演示体验环境"
    如果使用官方演示环境，平台已内置演示数据，**教师与学生全部功能均可直接体验**：

    - 教师：手机号 `13800138000` / 密码 `123456`
    - 学生：凭班级邀请码免密进入（如 `MATH2026`）

    演示环境的数据**不做长期保存**，容器重启或平台更新后会重建，请勿录入重要或真实信息。

---

## 二、注册与登录（教师）

### 注册

1. 在登录页点击「注册」
2. 填写手机号、密码、姓名（邮箱、学校可选）
3. 提交完成注册

### 登录

1. 输入手机号和密码
2. 点击「登录」

首次登录后若资料不完整，系统会提示前往「系统设置」补充。

!!! note "忘记密码"
    在登录页点击「忘记密码」，按提示通过密保问题重置。

---

## 三、配置 AI 服务（关键一步）

QuickClass 的对话、分析、出题等能力都依赖大模型，**首次使用必须配置 AI 服务**。

1. 进入「系统设置」页面
2. 填写 **API Base URL**（支持 OpenAI 兼容接口，如通义千问、DeepSeek、智谱等）
3. 填写 **API Key**
4. 选择 **AI 模型**（如 `qwen-turbo`、`deepseek-chat`）
5. 点击「测试连接」确认可用
6. 点击「保存配置」

!!! warning "AI 无法回答问题时"
    先检查「系统设置」里的 API Key 是否正确、Base URL 是否可访问，再点「测试连接」验证。

---

## 四、创建班级

1. 进入「班级管理」
2. 点击「创建班级」，填写班级名称与邀请码（可自定义）
3. 保存后**记录邀请码**——学生用它加入班级
4. 可选：开启「开放邀请码注册」，学生可自助注册

---

## 五、创建课堂

1. 进入「课堂管理」，点击「新建课堂」
2. 填写：课堂标题、课堂目标、年级、学科、班级（均为必填）
3. 点击「保存」——课堂自动展开并进入编辑模式
4. 在学习活动区添加：**对话活动 / 互动探究 / 项目提交 / 课堂作业**
5. 检查无误后，把课堂状态改为「**已启用**」，学生即可见

!!! tip "课堂目标可以 AI 优化"
    填写课堂目标后，点击「AI 优化」，系统会根据你输入的目标自动润色扩写。

---

## 六、学生加入

1. 学生访问 `http://<教师电脑IP>:3000/student`
2. 输入**姓名** + **班级邀请码**
3. 点击「加入」——系统自动建档，无需注册
4. 进入课堂开始对话、探究、答题

!!! note "学生姓名不能重复"
    同一班级内学生姓名不可重复。
