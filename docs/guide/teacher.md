# 课堂、班级与学习活动

本文介绍教师端的核心操作：课堂管理、班级管理，以及四类学习活动（对话活动、互动探究、项目提交、课堂作业）。

---

## 一、班级管理

1. 进入「班级管理」页面
2. 创建新班级，每个班级自动生成**邀请码**
3. 学生通过邀请码加入班级
4. 可设置是否**开放邀请码注册**（开启后学生可自助注册）

---

## 二、创建课堂

1. 进入「课堂管理」页面
2. 点击「新建课堂」
3. 填写课堂信息：

    | 字段 | 说明 | 必填 |
    |---|---|---|
    | 课堂标题 | 如「一元一次方程」 | ✅ |
    | 课堂目标 | 本课堂的学习目标 | ✅ |
    | 年级 | 适用年级 | ✅ |
    | 学科 | 学科 | ✅ |
    | 班级 | 分配到哪个班级 | ✅ |

4. 点击「保存」

创建成功后，课堂自动展开并进入对话活动编辑模式。

### 课堂状态

| 状态 | 说明 |
|---|---|
| 已停用 | 课堂未发布，学生不可见 |
| 已启用 | 课堂已发布，学生可见可使用 |
| 已归档 | 课堂已结束，学生不可见 |

!!! tip "课堂目标支持 AI 优化"
    填写课堂目标后点击「AI 优化」，系统会根据你写的内容自动润色扩写。

---

## 三、对话活动

对话活动是学生与 AI 进行主题对话的核心载体。

### 编辑对话活动

1. 在课堂列表中展开目标课堂
2. 点击「活动管理」进入编辑模式
3. 可添加、编辑、删除对话活动

### 对话活动字段

| 字段 | 说明 | 必填 |
|---|---|---|
| 对话活动名称 | 活动标题，如「什么是方程？」 | 是 |
| 对话活动目标 | 活动描述和学习目标 | 是 |
| 对话提示词 | 注入 AI 的系统提示词，决定 AI 的角色与行为 | 是 |
| 个人学情分析提示词 | 生成学生个人分析时使用的提示词 | 是 |
| 全班学情分析提示词 | 生成全班分析时使用的提示词 | 是 |

### 启用 / 禁用与排序

- 每个对话活动旁有开关：禁用后学生端不再显示，**已有对话记录不会删除**
- 用上下箭头调整顺序，学生端按此顺序显示

---

## 四、互动探究

互动探究是 HTML 交互式学习活动，支持学生操作和提交。

### 创建探究活动

1. 在课堂展开区域，点击「互动探究」面板
2. 点击「新建探究」，填写标题、描述
3. 编辑 HTML 交互内容（支持直接编辑 HTML 代码）

### AI 生成题目

1. 编辑探究内容后，点击「AI 生成题目」
2. 系统根据探究内容自动生成 4 道题目（1 单选 + 1 多选 + 1 填空 + 1 简答）
3. 生成后可手动调整

!!! warning "已有提交后锁定"
    已有学生提交后，**不可修改探究内容和重新生成题目**。

### 提交功能

- 开启后学生可提交探究结果
- 已有提交后，内容和提交开关将被锁定

---

## 五、项目提交

项目提交与对话活动、互动探究**并列**挂在学习活动下，是课堂内的第四类学生活动。

### 新建项目

1. 在课堂的「项目提交」面板点击「新建项目」
2. 输入项目名称（年级 / 学科自动从课堂带入，可修改）
3. 设置项目类别：**文本类 / 图片类 / 音视频类**
4. 设置是否全班可见、是否允许点赞（开点赞自动开全班可见）
5. 设置文件大小限制（单位 MB，默认 10）
6. 保存后出现在列表中，左侧显示「生效中 / 失效中」

### 生效开关与排序

- 用 Switch 控制项目是否对学生可见
- 生效中的项目支持 ↑↓ 拖拽排序

### 浏览全班提交

- 点击「浏览」在当前页面打开**照片墙视图**
- 顶部 [2列][3列][4列][6列] 切换网格密度
- 点击图片弹出全屏灯箱查看原图
- 非图片类显示占位区 + 查看文件链接

### 置顶与下架

- ↑ 箭头将提交排到全班最前（红色表示已置顶，再点取消）
- ↓ 箭头隐藏提交（仅学生本人可见，红色表示已下架，再点恢复）
- 二者互斥：置顶状态下不可下架，需先取消置顶，反之亦然
- 下架项目教师端排最后且姓名显示「***」

### 点赞

教师和学生均可点击爱心 ♥ 点赞 / 取消，红色表示已点赞，每人每个项目仅一次。

### 编辑与删除

- **编辑**：修改项目任务不影响已提交学生的项目与附件，仅对后续提交与未提交者生效
- **删除**：级联删除该任务下所有学生提交及附件记录，并物理删除磁盘附件文件

---

## 六、课堂作业

### 创建作业

1. 在课堂展开区域，点击「作业管理」
2. 点击「新建作业」，填写作业标题和描述

### 添加题目

1. 进入作业详情，点击「添加题目」
2. 选择题型：**单选题、多选题、判断题**
3. 填写题目内容、选项、答案、分值、难度
4. 也可使用 **AI 自动生成题目**

!!! note "题型限制"
    课堂作业仅支持**单选、多选、判断**三种题型，**不支持填空和简答**（填空、简答仅用于互动探究的 AI 生成题目）。

### 作业状态

| 状态 | 说明 |
|---|---|
| 未生效 | 草稿状态，学生不可见。编辑保存后自动回到此状态 |
| 已生效 | 已发布，学生可答题。需至少添加一道题目才能生效 |

!!! warning "每次编辑都会回到「未生效」"
    编辑保存作业后状态自动变为「未生效」，需**重新发布**。

### 统计与报告

- **统计**：查看答题人数、平均分、正确率
- **报告**：AI 自动生成作业分析报告
